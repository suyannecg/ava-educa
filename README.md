# AVA-EDUCA+

## Sobre o projeto
Projeto avaliativo final do Módulo 1, desenvolvido para o curso Front-End Angular do SCTec.

O AVA-EDUCA+ foi construído para centralizar as informações dos cursos disponibilizados por uma empresa especializada em educação profissional, facilitando o acesso e o trabalho do corpo pedagógico. A solução busca facilitar a consulta de cursos e o cadastro de alunos pelos professores em um único ambiente. Além disso, o sistema possui uma interface responsiva, permitindo o acesso tanto por computadores quanto por dispositivos móveis.

## Tecnologias e Técnicas utilizadas
### Tecnologias:
- HTML, CSS e JavaScript;
- Moment.js para validação da data de nascimento no cadastro de alunos;
- API ViaCEP para consulta de endereço a partir do CEP;
- Git e GitHub para versionamento do projeto e organização do desenvolvimento.

### Técnicas:
- Manipulação de DOM e eventos;
- Arrays e objetos;
- Funções e callbacks;
- Estruturas condicionais e de repetição;
- POO;
- Promises e assincronicidade;
- Consumo de API externa;
- Organização do JavaScript com ES Modules;
- Armazenamento com sessionStorage;
- Manipulação de dados com JSON;
- Layouts com Flexbox e CSS Grid;
- Media Queries para responsividade (desktop e dispositivos móveis);
- Validação de formulários com HTML;
- Desenvolvimento através de branches e commits.

## Como executar
1. Clone este repositório e abra a pasta do projeto no VS Code;
2. Baixe a extensão Live Server se necessário e selecione a opção 'Open with Live Server' no arquivo index.html;
3. Acesse o sistema utilizando um dos dados disponíveis para demonstração.
